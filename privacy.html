Zásady ochrany soukromí

Platí pro aplikaci PPC Čechová (interní nástroj, provozovatelka Barbora Čechová). Účinnost od 16. 10. 2026.

Jaká data aplikace zpracovává

Po přihlášení účtem Google a udělení oprávnění Google Ads API aplikace čte nastavení a statistiky reklamních účtů (kampaně, sestavy, reklamy, klíčová slova, vyhledávací dotazy, historii změn) a na pokyn uživatelky provádí schválené změny v těchto účtech.

Kde se data ukládají

Data se ukládají pouze lokálně na počítači provozovatelky. Přihlašovací tokeny jsou uložené v systémové klíčence nebo v chráněném konfiguračním souboru na tomtéž počítači.

Sdílení

Data nejsou prodávána ani předávána třetím stranám a nejsou používána k reklamě ani k jiným účelům než ke správě a vyhodnocení příslušných reklamních účtů.

Odvolání přístupu a smazání

Přístup lze kdykoli odvolat na myaccount.google.com/permissions. O smazání uložených dat lze požádat e-mailem na níže uvedené adrese.

Využití informací získaných z Google API se řídí zásadami Google API Services User Data Policy, včetně požadavků Limited Use.

English summary

The app reads Google Ads account settings and statistics and, on the owner's instruction, applies approved changes. Data is stored only locally on the owner's computer, is never sold or shared with third parties, and is used solely to manage and report on the respective ad accounts. Access can be revoked at any time at myaccount.google.com/permissions. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
